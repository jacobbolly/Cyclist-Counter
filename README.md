# 🚴 Cyclist Counter

A simple web application built with **HTML, CSS, and Vanilla JavaScript** that tracks the number of cyclists completing a ride. Users can increment the cyclist count, save previous totals, and reset the counter for the next group.

This project was created as part of my JavaScript learning journey while completing the **Scrimba JavaScript Course**, with a focus on building a strong understanding of DOM manipulation, event handling, and fundamental programming concepts.

## ✨ Features

- 🚴 Increment cyclist count with a single button click
- 💾 Save previous cyclist totals
- 🔄 Reset the counter after saving
- 🖼️ Cycling-themed background image
- 📱 Responsive centered card layout
- 🎨 Custom styling using CSS
